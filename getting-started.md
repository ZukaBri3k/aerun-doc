# Getting started

## Install and choose a preset

1. In the Shopify Theme Store, open AERUN and choose **Try theme** or **Buy theme**. The theme is added to *Online Store → Themes*.
2. Select **Customize** to open the theme editor.
3. To change preset, go to *Theme settings → Theme styles* and pick Aerun, Ridge or Interval. Changing the style replaces your theme settings (colors, fonts, corners), not your sections or content.
4. When the store looks right, select **Publish**.

## First steps

- **Logo**: in the Header section, set the *Logo image* and its width. Set the *Favicon* in *Theme settings → Logo and favicon*.
- **Colors and fonts**: *Theme settings → Colors* and *Typography*. See [Presets and colors]({{ '/presets/' | relative_url }}).
- **Menus**: create them in *Online Store → Navigation*, then choose them in the Header and Footer sections. See [Navigation]({{ '/navigation/' | relative_url }}).
- **Customer service**: fill in *Theme settings → Customer service* (email, phone, opening hours, announced response time, contact page, returns portal). The footer, the contact page and the cart reuse these details.
- **Cart**: *Theme settings → Cart* sets a drawer or a cart page, the order note, accelerated checkout buttons, suggestions and the cart extras (free shipping threshold, gift message, add-on product, reassurance lines).
- **Running data**: create the metafield definitions and fill in your products. See [Products and running data]({{ '/products-and-data/' | relative_url }}).

## Templates included

A product or a page uses an alternate template when you choose it in the *Theme template* field of its admin page. These templates appear there only when AERUN is the published theme.

### Products

| Template | For |
| --- | --- |
| Default product | Any product |
| `shoe` | Running shoes: specs, drop and stack, profile, fit advice, technologies |
| `apparel` | Clothing: fit, model, materials, care symbols |
| `hydration` | Flasks, vests and accessories: capacity, contents, instructions |
| `nutrition` | Gels, bars, drinks: nutrition facts, ingredients, allergens |
| `gift-card` | Gift card products |

### Pages

Create a page in *Online Store → Pages*, then choose its template.

| Template | Page |
| --- | --- |
| `about` | Brand story, team, commitments |
| `campaign` | A product launch or a campaign |
| `compare` | Product comparison (choose it as the *Comparison page* in *Theme settings → Running data*) |
| `contact` | Contact form and customer service details |
| `events` | Upcoming events |
| `gifts` | Gift guide by budget |
| `glossary` | Technical glossary |
| `help-center` | Help center with FAQ |
| `returns` | Returns and exchanges |
| `road`, `trail`, `training` | Landings for each running discipline |
| `shipping` | Shipping information |
| `shoe-finder` | A short guided choice that points to the right shoes |
| `size-guide` | Size guides |
| `stores` | Points of sale |
| `technology` | Technologies used in your products |

### Others

- Collections: `usage` (a collection by use, with a guide and FAQ) and `campaign` (a sale or a seasonal collection).
- Articles: `guide` (buying guide) and `interview`.
