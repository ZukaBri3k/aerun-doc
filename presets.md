# Presets and colors

## Presets

A preset is a set of theme settings. AERUN has three:

| | Aerun | Ridge | Interval |
| --- | --- | --- | --- |
| Page color scheme | Light | Dark | Light |
| Primary button | Electric pink, dark text | Ochre, dark text | Blue, white text |
| Headings | Barlow Condensed, uppercase | Oswald, uppercase | Archivo |
| Body text | Inter | Work Sans | DM Sans |
| Corners | Small | Square | Pill buttons, rounded cards and images |
| Section spacing | Standard | Standard | Airy |

Specs and prices always use IBM Plex Mono, so figures line up.

To switch, open *Theme settings → Theme styles*. Switching replaces the theme settings with the preset's values. Your sections, blocks and content stay as they are.

## Color schemes

Every preset has five color schemes with the same names: **Light**, **Surface**, **Secondary**, **Dark** and **Ice**. Sections and blocks choose one in their *Color scheme* setting, so a page keeps working whichever preset you use.

Edit them in *Theme settings → Colors*. Each scheme has a background, text, secondary text, border, accent, link, button and button label color.

The schemes shipped with the theme meet WCAG AA contrast: 4.5:1 for text and buttons, 3:1 for accents. If you change a color, check the contrast of its text against its background, for example with the WebAIM contrast checker.

## Shapes, type and spacing

- *Theme settings → Typography*: display, body and data fonts, and uppercase headings.
- *Theme settings → Shapes*: corners of buttons, cards, images and form fields.
- *Theme settings → Layout*: page width and section spacing (compact, standard, airy).
- *Theme settings → Animations*: reveal sections on scroll. It is off for visitors who ask their device to reduce motion.
