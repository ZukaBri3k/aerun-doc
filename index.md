# AERUN

AERUN is a Shopify theme for running stores: road, trail and training. It turns running specs into a clear product page, a spec sheet with drop and stack, fit advice, size guides, technologies and a side-by-side comparison, all built on documented metafields.

## Three presets

| Preset | For | Look |
| --- | --- | --- |
| **Aerun** | Road running | Light, electric pink buttons, condensed uppercase headings |
| **Ridge** | Trail running | Dark and earthy, ochre buttons, square corners |
| **Interval** | Training and apparel | Light and neutral, blue pill buttons, airy spacing |

The presets share the same sections and blocks. Only the theme settings differ: colors, fonts, corners and spacing. See [Presets and colors]({{ '/presets/' | relative_url }}).
