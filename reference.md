# Sections and blocks reference

Every section and block you can add in the theme editor, with its presets and settings. For when to use each one, see [Building pages]({{ '/sections/' | relative_url }}).

## Sections

### Anchored sub-navigation

- **Settings**: Accessible name, Color scheme

### Announcement bar

- **Blocks**: Announcement
- **Settings**: Color scheme, Rotate announcements, Change every, Let visitors dismiss the bar

### Banner

- **Presets**: Campaign banner, Countdown, Call to action
- **Blocks**: theme blocks, app blocks
- **Settings**: Image, Layout, Alignment, Dates, Conditions, Countdown end, After the end, Text after the end, Anchor label, Color scheme, Spacing
