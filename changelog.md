# Changelog

All notable changes to the AERUN theme are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/).

- **Major**: changes that need action from the merchant (a removed setting, a renamed section, a data migration).
- **Minor**: new sections, blocks or settings, compatible with existing stores.
- **Patch**: fixes.

## [1.0.0] - Unreleased

First release, for the Shopify Theme Store.

### Added

- **Presets**: Aerun (road), Ridge (trail) and Interval (training), built on the same sections and blocks, each with five color schemes that pass WCAG AA contrast.
- **Foundation**: design system (color schemes, typography, spacing, shapes), header with mega menu, footer, English and French translations, accessibility (focus, skip link, reduced motion).
- **Purchase**: product page with variant picker, swatches, size guide, media gallery with zoom lightbox, 3D models and videos, quick add, cart drawer and cart page, gift cards, pickup availability, unit prices, selling plans, accelerated checkout.
- **Discovery**: collection pages with Shopify filters and sorting, running facets, predictive search, search page, product recommendations.
- **Running data**: a documented `aerun` metafield and metaobject contract with specs, drop and stack, fit advice, size guides, terrain, technologies, proofs, nutrition, product comparison and a shoe finder.
- **Content**: hero, slideshow, media with text, grid presets, banner with countdown, FAQ, featured product, collection tabs, featured articles, anchor navigation, blog and article pages with table of contents and reading time, people, stores, events, testimonials, contact form, kit, checklist, recently viewed.
- **Cart extras**: free shipping progress per currency, gift message, club reference, add-on product, reassurance.
- **Demo**: a demo data set and setup script for the Shopify Admin API.
