## What support covers

- Bugs in the theme.
- Help with theme settings, sections, blocks and presets.
- Installing the theme and setting up the running data described in this documentation.

## What it doesn't cover

- Custom code changes, including changes made by you or a developer.
- Third-party apps and their blocks: contact the app developer.
- Store setup outside the theme (payments, shipping rates, taxes, domains).

## Updates

AERUN follows semantic versioning: patch versions fix bugs, minor versions add features, major versions may need an action from you, always explained in the [changelog]({{ '/changelog/' | relative_url }}). We keep the theme compatible with Shopify's changes. Fixes go into the latest version, so keep your theme up to date from *Online Store → Themes*.
